## 二、拿到代码（三选一）

**方式 A：直接下载 zip（最简单）**

打开 https://github.com/danta2006/map → 绿色「Code」→「Download ZIP」→ 解压到 `C:\微信小程序`（或任意没有中文/空格的路径）。

**方式 B：git clone**

```powershell
git clone https://github.com/danta2006/map.git
cd map
```

**方式 C：下载打好的 Release 包**

在仓库右侧「Releases」里点 `v0.9.3`，下载 Source code (zip)。

---

## 三、导入项目

1. 打开微信开发者工具 → 导入项目
2. 目录选择上一步解压/克隆出来的文件夹（`project.config.json` 所在的那一层）
3. AppID 填：**`wx8f72fd67cbda3aa9`**（项目里已写好，一般会自动带出；不要换成你自己的 AppID，否则云开发不可用）
4. 点「确定」→ 直接编译即可看到地图

> 首次编译如果提示「无权限/无法预览」，说明你的微信还没被加进小程序成员，见第四节。

---

## 四、让管理员给你开权限（必须做一次）

管理员（项目主）操作：

1. 微信公众平台 https://mp.weixin.qq.com → 登录小程序后台
2. 左侧「成员管理」→「开发成员」→ 添加你的微信号
3. 用管理员微信扫码确认

之后你用**自己的微信**登录开发者工具，就拥有：

- 本地编译、真机预览
- 上传体验版（右上「上传」按钮）
- 云开发控制台（同一个云环境 `cloud1-d5ghzdcqba4c291f8`）

> 「体验版」需要管理员在后台「版本管理」里把你上传的版本设为体验版，才算正式发布给体验成员。

## 五、你**不需要**、也不要找管理员要的东西

| 东西 | 为什么不要 |
|---|---|
| **AppSecret** | 等于小程序后台钥匙，能换 access_token 调接口；开发成员用自己微信就够了 |
| 管理员电脑的 `admin/.env.local` | 里面是后台密钥/令牌，且不在仓库里 |
| 管理员的 GitHub Token | 仓库公开，不需要 |

> 仓库里本来就没有这些文件（`.gitignore` 已排除），你 clone 下来也不会看到。

## 六、日常开发命令

```powershell
# 编译/预览：开发者工具里点「编译」「预览」即可

# 页面接线检查（改完 wxml/js 必跑）
node scripts/check_pages.js

# 部署云函数（改了 cloudfunctions/ 下代码才需要）
cli cloud functions deploy --env cloud1-d5ghzdcqba4c291f8 --names feedback userRoutes initEnv ping -r --project .

# 上传体验版（开发者工具「上传」等价）
cli upload --project . -v 0.9.4 -d "说明"
```

> `cli` 是微信开发者工具自带的命令行（安装目录 `cli.bat`），也可以直接用工具界面操作。

## 七、内容后台（可选，改点位/路线文案时才用）

后台是**本地工具**，不在小程序里跑：

```powershell
cd admin
copy .env.local.example .env.local   # 然后填你自己的配置
cd ..
node admin/server.js
# 浏览器打开 http://127.0.0.1:8787
```

`admin/.env.local` 里需要：

- `AMAP_KEY`：高德 Web 服务 Key（**用自己的**，去 https://console.amap.com 申请，个人免费）
- `WX_APPSECRET`：**不要用管理员的**；不填也能用「点位/路线编辑」，只是「从云端同步反馈/社区路线删除」用不了
- `CLOUD_ENV=cloud1-d5ghzdcqba4c291f8`

改完内容点「导出到小程序」，再 `git commit` 提交 `admin/data/*.json` 与 `miniprogram/data/*.js`。

## 十一、常见问题

| 现象 | 原因/解决 |
|---|---|
| 上传按钮点了提示无权限 | 你微信没被加为开发成员，找管理员加 |
| 云开发控制台打不开/环境看不到 | 确认 AppID 是 `wx8f72fd67cbda3aa9` 且登录的是已加成员的微信 |
| 上传后别人扫不到体验版 | 管理员要去小程序后台「版本管理」把该版本设为体验版 |
| 地图空白/不显示 | 检查网络；开发者工具里关掉「仅Wi-Fi」代理；重编译 |
| 改了数据没生效 | 数据是打包进去的静态文件，改完要重新编译；用后台改要「导出到小程序」 |
| 后台 401 | 后台有令牌鉴权，浏览器打开会自动带；curl 要加 `X-Admin-Token`（见 `admin/.env.local`） |
| 高德接口报配额 | 用自己的 Key，个人免费额度 5000 次/天 |
